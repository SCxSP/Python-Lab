# Python Lab - Sample Datasets

This directory contains sample datasets used across the Python Lab assignments (`Assi1` to `Assi10`).

---

## Dataset Catalog

### 1. `student.txt` & `source.txt` (Text Files)
- **Target Assignment**: `Assi7` (File Handling & Exceptions - Q21, Q22, Q23, Q24, Q25)
- **Description**: Sample formatted text files containing student details and plain text lines for testing read/write, readline, character/word counting, and copy operations.

---

### 2. `students.csv` (CSV Dataset)
- **Target Assignment**: `Assi8` (NumPy & Pandas - Q16, Q17, Q18, Q20, Q25)
- **Schema**:
  - `Roll`: Student roll number (Integer)
  - `Name`: Student name (String)
  - `Dept`: Academic department (`CS`, `IT`, `EC`)
  - `Marks`: Overall score (0-100)
  - `Attendance`: Attendance percentage (0-100)
  - `Maths`, `Physics`, `Chemistry`, `CS`: Subject marks (0-100)

---

### 3. `employees.csv` (CSV Dataset)
- **Target Assignment**: `Assi8` (Pandas - Q19, Q21)
- **Schema**:
  - `EmpID`: Employee ID (e.g. `EMP101`)
  - `Name`: Employee Name
  - `Department`: Department (`IT`, `HR`, `Finance`, `Marketing`)
  - `Salary`: Annual salary in INR
  - `Experience`: Years of experience

---

### 4. `monthly_sales.csv` (CSV Dataset)
- **Target Assignment**: `Assi8` (Matplotlib Visualization - Q22)
- **Schema**:
  - `Month`: Month abbreviation (`Jan` to `Dec`)
  - `Sales`: Total sales figure

---

### 5. `city_temperature.csv` (CSV Dataset)
- **Target Assignment**: `Assi8` (Matplotlib Visualization - Q24)
- **Schema**:
  - `Month`: Month abbreviation (`Jan` to `Dec`)
  - `Temperature_C`: Average monthly temperature in Celsius

---

### 6. `imports-85.data` & `automobile.csv` (UCI Automobile Dataset)
- **Target Assignment**: `Assi9` (Car Pricing & Exploratory Data Analysis - Q1 to Q23)
- **Source**: UCI Machine Learning Repository — [Automobile Dataset](https://archive.ics.uci.edu/dataset/10/automobile)
- **Description**: 205 instances, 26 attributes (car specifications, engine characteristics, fuel economy, and price). Missing values are represented as `?` in `.data` format.
